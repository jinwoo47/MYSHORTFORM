# MYSHORTFORM
A free, personal alternative to Shortform. Type any book or topic and get a summary, chapter breakdown, quiz, and a place for your notes.

I loved Shortform but didn't want another subscription, so I built my own version. MyShortform is a single web page that runs in your browser. Type in a book and it writes a summary, breaks it down chapter by chapter, and quizzes you so the ideas actually stick. There's also a research mode for any topic you're curious about, not just books.
Everything you save, your library and your notes, stays on your own device. You bring your own Anthropic API key, so you only pay for what you use.
How to use it:
Open the page and paste your API key at the bottom.
Type a book title or a topic.
Read, take the quiz, and add your notes.
The summaries are AI-written from the model's own knowledge, so double-check anything important.
